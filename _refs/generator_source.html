实时计分时间轴（对照视频编辑）

按视频绝对秒填写；生成 BAS 时会按「投放时间」自动换算成弹幕相对秒，用 then set 串联。点每行的 ⤴ 可让播放器跳到该秒核对画面；拖动右侧时间轴或点刻度可查看各时刻状态。

视频秒字段值

半局填「上/下」；垒包、布尔字段填「1/0」；其余填数字或文字。

使用方法：复制上方代码 → 在支持 BAS 的 B 站播放器「高级弹幕 / 代码弹幕」编辑器中粘贴并运行（需相应投稿权限）；或点「在官方试验室打开」直接调试。
无时间轴事件时输出静态记分条，所有元素 duration 相同、常驻画面；有事件时按视频绝对秒记录，生成时按「投放时间」换算成弹幕相对秒，用 then set 依次更新文字与指示灯。
左栏「在线视频 · 时间同步」可嵌入 B 站在线播放器（或载入本地视频文件）对照画面手工打点，时间轴刻度与事件表分别在右栏与左栏，支持刻度跳转、快捷事件、JSON 导入导出；示例视频画面无记分板，内置时间轴仅为演示数据。
右下角 B / S 两行记数、队伍行配色（写入 fillColor / color）与四角定位（按宽度换算 X/Y 百分比）都会在生成时固化到脚本里；颜色不支持在时间轴中途切换（BAS 的 path 不能在 set 中改 fillColor）。
