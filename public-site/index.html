无时间轴事件时输出静态记分条，所有元素 duration 相同、常驻画面；有事件时按视频绝对秒记录，生成时按「投放时间」换算成弹幕相对秒，用 then set 依次更新文字与指示灯。
左栏「在线视频 · 时间同步」可嵌入 B 站在线播放器（或载入本地视频文件）对照画面手工打点，时间轴刻度与事件表分别在右栏与左栏，支持刻度跳转、快捷事件、JSON 导入导出；页面不预置任何视频或比赛数据，时间轴由使用者手工打点或从自己的 JSON 导入。

直播控制与视频导出（线上实时控制需主动连接 · 视频与文件处理全在本机）

① 线上直播叠加层（跨设备实时控制）

控制器与 OBS 浏览器源可以在不同设备。连接后本页改动按房间号实时推送给同房间叠加层，不同房间互不干扰。未连接时页面完全离线，也可用 URL 快照或本地文件独立运行。

未连接 · 房间数据不会离开本机

OBS 浏览器源填上面的「叠加层地址」（已带 ?room=…&panel=0），宽 1920 / 高 1080、勾选透明背景。消息只在中继内存转发、不落盘；控制器另有随机控制密钥，别人知道房间号也只能观看。按 H 隐藏面板、空格 暂停、←/→ ±5 秒。手机 / 平板可打开同目录 mobile-control.html（短地址 /m.html）选择房间加入；「复制手机控制地址」会带上房间号与控制密钥，只发给自己的手机，不要公开分享。

② 本地视频烧录导出（可选格式）

先在上方「在线视频 · 时间同步」选择本地视频，再把同一份 SVG 记分条逐帧叠进画面。录制按视频原速实时进行，请保持此标签页在前台。
